# MangaOCR App

**Десктопное приложение для распознавания японского текста в манге и иллюстрациях.**

Приложение построено на базе специализированной модели для распознования текста - [manga-ocr](https://github.com/kha-white/manga-ocr) и детектора текста в манге - [yolo](https://huggingface.co/deepghs/manga109_yolo)

![Главное окно приложения](https://github.com/user-attachments/assets/99f2b187-74ec-478d-8109-6ebe6359b388)

## Возможности

- Высокоточное распознавание японского текста в манге
- Поддержка **CPU** и **GPU** (NVIDIA CUDA)
- Пакетная обработка нескольких изображений
- Настройка интефейса под себя
- Экспорт текста в word или txt форматы
- Встроенный японо-русский словарь Jardic
- Загрузка сканов с Rawkuma
